# TPD-Addin-XLAM

A macro-enabled add-in supporting various business functions at TPD.

## Download

The latest built add-in (`TPD_Addin.xlam`) is published on the **[Releases page](https://github.com/srjohnson1986/TPD-Addin-XLAM/releases)** — grab the `.xlam` attached to the most recent release and install it per the guide below.

## Documentation

For the install guide, usage instructions, and troubleshooting: **[User Guide](docs/USER_GUIDE.md)** (also on the [wiki](https://github.com/srjohnson1986/TPD-Addin-XLAM/wiki)).

## About this repo

This repo is migrating from tracking the compiled `.xlam` directly to tracking its VBA source (`/src`) instead, with the built `.xlam` published as a versioned Release rather than committed to the repo. See Releases for stable downloads; source and build tooling will live here as that migration progresses.
